Units & Packagings uom.uom

Every unit of measure and packaging in one worksheet. A unit is a multiple — Contains — of its Reference Unit, up to a unit that has none. Absolute Quantity multiplies that chain out (km = 1000 × m’s 1000 = 1,000,000) and is what every later unit conversion reads.

Worth knowing before you review

Absolute Quantity is hidden, as in Odoo — check it from the CLI

The form shows Unit Name, Contains and Reference Unit only. Absolute Quantity, Sequence and the recursion check’s Parent Path are hidden. To see them for any unit, run ~/.hap-venv/bin/python nocoly/build/units.py unit "Unit Name"; units.py verify compares all 30 standard units with Odoo.

Two more hidden lookups — the Reference Unit’s Absolute Quantity and Parent Path — feed the formulas.

Rules

All three are validation rules, checked in the form and on API writes.

RuleWhenMessageOdoo source
Contains cannot be 0Contains = 0“The conversion ratio for a unit of measure cannot be 0!”, as you typeSQL constraint _factor_gt_zero
A unit without a Reference Unit contains 1No Reference Unit and Contains ≠ 1“Reference unit of measure is missing.”, on submit_check_factor
Reference Unit cannot be the unit or one below itThe chosen unit’s Parent Path contains this unit“Recursion Detected.”, as you pickORM _parent_store recursion check

Without the third rule a reference loop (km → m → km) would make HAP recompute Absolute Quantity endlessly.

Differences from Odoo seen in testing

  1. 1
    Reference Unit pickerNote

    Odoo’s dropdown hints each unit’s ratio (“Days 8.0 Hours”); HAP lists names only. The ratio shows once a unit is picked. Its search also matches the Reference Unit column: “Units” finds Pack of 6.

  2. 2
    New records sit at the top of the open viewHAP behaviour

    Until the view is refreshed, whatever their Sequence.

    Archive and UnarchiveNote

    The button that does not apply is greyed out rather than hidden, as on Contacts.
